# Responsive Authentication UI (Login & Sign Up)

A clean, responsive user authentication interface featuring dynamic Login and Sign Up forms styled with smooth gradient accents and viewport-relative scaling.

## Features

* **Unified Gradient Aesthetics:** Features a modern blue-to-purple linear gradient background (`skyblue` to `purple 80%`) applied across background containers and submit buttons.
* **Viewport-Based Responsive Design:** Built using Viewport Height (`vh`) and Viewport Width (`vw`) units, ensuring fonts, input fields, padding, and layout cards scale proportionally across different display sizes.
* **Left-Aligned Card Layout:** Structured using CSS Flexbox for clear alignment and horizontal balance across large screens.
* **Form Page Navigation:** Includes seamless cross-linking between the Login (`signup.html`) and Sign Up (`index.html`) templates.
* **Pure HTML5 & CSS3:** Zero external frameworks or JavaScript dependencies required.
